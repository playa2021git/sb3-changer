# Gemに渡す資料

このフォルダは、Gemini側のカスタムGemへ渡す資料をまとめたものです。
`docs/` や `README.md` は開発者向けなので、Gemには添付しないでください。

## カスタム指示欄に貼るもの

- `gem-instruction.txt`

## 添付する4ファイル

1. `../stretchscript-spec.md` （対応関数の一次資料）
2. `classroom-rules.md` （スプライトの大きさ、画面配置、実機テストの決まり）
3. `examples.md` （動作確認済みの出力例）
4. `microbit-more.md` （micro:bitの関数一覧とメニュー値）

## 添付してはいけないもの

| ファイル | 理由 |
| --- | --- |
| `README.md` | コード枠記号が多数含まれ、出力形式の指示と矛盾する |
| `index.html` | 画面の作りであって、言語の説明ではない |
| `docs/archive/` の資料 | 履歴資料。現在の対応範囲と食い違う |
| `definitions/*.json` | 未対応ブロックのopcodeまで見えてしまう |

## 授業で使わせる範囲を広げるとき

変換器は公式31ブロックすべてを通します。生徒に使わせる範囲は `microbit-more.md` の
「授業で使ってよい範囲」で管理します。

実機で動作を確認できたブロックを、この見出しの下に1行ずつ足してください。
変換器のコードを触る必要はありません。

## 更新したとき

`gem-instruction.txt` や添付ファイルを直したら、Gemの設定画面で古いファイルを削除してから
新しいファイルを添付し直してください。古いファイルが残っていると、Gemはそちらを読みます。
